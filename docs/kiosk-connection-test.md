# 自助報到連線的安全開發測試

執行 `npm run test:kiosk`。測試使用現有 Chrome 或 Edge 的獨立無頭瀏覽器、實際報到元件與路由處理函式。

每次測試在系統暫存目錄建立全新的 SQLite 資料庫，只放入合成預約。資料庫連線明確指向該檔案，測試用資料存取層停用環境檔載入；不使用專案的實際資料庫或環境檔。測試結束會關閉瀏覽器與本機服務並移除暫存資料庫。

簡訊替身僅監聽本機迴路位址，驗證碼只保留在測試記憶體；不發送真實簡訊、不輸出驗證碼、不保存畫面截圖、憑證、資料列或日誌。

## 成功案例

從數字鍵盤輸入合成電話，按查詢、輸入替身收到的驗證碼、按驗證，再按確認報到。確認三個原有服務依序收到請求，畫面顯示報到成功後返回首頁；核對資料庫報到狀態、稽核事件及紀錄鏈。

## 失敗案例

輸入錯誤驗證碼時應回傳 401，畫面顯示錯碼提示，不進入確認報到，不更新報到狀態，並記錄失敗稽核。

額外驗證簡訊替身回傳非成功狀態時，查詢服務回傳 503，畫面顯示安全提示而不宣稱已傳送，未送達的驗證碼必須失效。

## 證據與限制

測試通過或失敗都會以原子替換方式更新 src/data/kioskConnectionVerification.json。通過紀錄僅含時間、範圍、情境名稱、路由、回應碼及布林檢查結果；失敗紀錄僅保留時間、失敗判定與固定安全摘要，不保留例外內容。

管理員權限檢查通過後，伺服器每次請求都重新讀取該檔案，檢查命令、時間及通過案例的回應碼與儲存／稽核證據，僅輸出允許的欄位及固定中文摘要。頁面顯示期間每 30 秒更新，切回頁面時也更新；更新不會重跑測試。不合法或缺失的紀錄顯示尚無可對應的測試時間，不沿用建置時的舊成功結果。測試時間與來源掃描時間分開。

執行 `npm run test:kiosk-dashboard` 可在暫存目錄驗證報告替換後，不重載模組就能更新畫面的時間、安全摘要及相關連線；並檢查失敗、缺失、格式錯誤、敏感資料排除及定時更新。此測試不改寫實際報到測試紀錄，也不把報到元件或簡訊升級成已連接。

測試執行器與網站必須共用同一部署目錄；遠端網站不會讀取開發電腦上的紀錄。部署時需包含上述安全紀錄檔並以專案目錄為啟動目錄；若平台不提供檔案系統或為多副本部署，需另外建置共用證據儲存，本次未宣稱已完成該遠端整合。

這是隔離開發整合測試，不涵蓋 Next 中介層、正式部署、真實簡訊供應商或掃描設備。簡訊供應商及完整報到元件仍維持部分連接，直到另有實際服務證據。
