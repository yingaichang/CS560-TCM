# Images Directory

## Bamboo Hero Image

**File:** `bamboo-hero.webp`

**Recommended Specifications:**
- **Dimensions:** 1920 × 1080px (16:9 aspect ratio)
- **Format:** WebP (for optimal performance) or JPEG as fallback
- **File Size:** 200-400KB (optimized for web)
- **Color Profile:** sRGB
- **Content:** Bamboo forest or nature scene with depth

**Design Notes:**
- Left side will be covered by warm beige gradient overlay (#e8dcc8)
- Keep important visual elements toward the right/center
- Image should have good contrast and clarity
- Natural lighting preferred to maintain warm, inviting aesthetic

**How to Add:**
1. Export or save your bamboo forest image as WebP format
2. Optimize for web (compress while maintaining quality)
3. Place the file in this directory with the name `bamboo-hero.webp`
4. The hero banner will automatically display with the left gradient overlay

**Example Source:**
You can find high-quality bamboo forest images from:
- Unsplash: https://unsplash.com (search "bamboo forest")
- Pexels: https://pexels.com (search "bamboo")
- Pixabay: https://pixabay.com (search "bamboo forest")

**Optimization Tool:**
Use any of these tools to convert to WebP and optimize:
- https://cloudconvert.com/ (online converter)
- ImageMagick (command line): `convert input.jpg -quality 80 output.webp`
- Squoosh (https://squoosh.app/) - Google's online image optimizer
